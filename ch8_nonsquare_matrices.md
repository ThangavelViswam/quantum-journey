# Chapter 8: Nonsquare Matrices as Transformations Between Dimensions

## Key Concept
- Nonsquare matrices transform between different dimensions
  - 3x2 matrix → transforms 2D space into 3D space
  - 2x3 matrix → transforms 3D space into 2D space

## Reading a Nonsquare Matrix
- Number of columns = dimensions of input space
- Number of rows = dimensions of output space
- Columns still tell you where basis vectors land

## Examples
- 3x2 matrix: input 2D vector → output 3D vector (2D plane into 3D space)
- 2x3 matrix: input 3D vector → output 2D vector (3D projected to 2D plane)

## Rank Still Applies
- Rank = dimensions of output column space

## Quantum Computing Connection
- Measurement is a nonsquare operation
- Collapses high-dimensional quantum state down to classical 0 or 1
- Same idea as a 3D to 2D projection
