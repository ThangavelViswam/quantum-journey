# Chapter 5: Three-Dimensional Linear Transformations

## Key Concepts
- Everything from 2D directly extends to 3D
- Third basis vector k-hat = [0, 0, 1] along z-axis
- A 3D transformation is described by a 3×3 matrix
  - Each column = where i-hat, j-hat and k-hat land after transformation

## Matrix × Vector in 3D
- [a b c]   [x]   [ax + by + cz]
- [d e f] × [y] = [dx + ey + fz]
- [g h i]   [z]   [gx + hy + iz]

## Key Insight
- Composition still works the same — multiply matrices to combine transformations
- Same logic as 2D, just one more dimension

## Quantum Computing Connection
- Qubit state vectors live in complex vector spaces (like 3D but with complex numbers)
- Multi-qubit systems use even higher dimensional spaces — same matrix logic applies
